
# Late Delivery Risk Analysis

This project analyzes late deliveries and builds a machine-learning model to predict late-delivery risk.

## Project contents
- Data cleaning and preparation
- Exploratory data analysis
- One-hot encoding for categorical variables
- Numerical-feature scaling
- Time-aware train/test split
- Late-delivery risk prediction model

## Tools used
Python, Pandas, NumPy, Matplotlib, Scikit-learn

## How to run
Open the `.ipynb` notebook in Jupyter Notebook or Google Colab and run the cells in order.
